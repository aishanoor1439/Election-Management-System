> **BUSPs (Bahria University Society Polls)** is a fully automated, user-friendly election management system for Bahria University. It addresses the inefficiencies of manual student society elections by providing secure, transparent, and reliable voting using Java Swing for GUI and MariaDB for backend management.

---

## ✨ Key Highlights

✔ Automated election management
✔ Secure login for admins and students
✔ Accurate vote counting and result calculation
✔ Transparent and efficient voting system
✔ Society-wise candidate and voter management

---

## 📌 Introduction

Student societies are essential for campus life, nurturing leadership and teamwork skills. Manual election systems face issues like delayed results, inaccurate vote counting, and lack of transparency. **BUSPs** solves these challenges with a GUI-based, automated voting platform.

---

## 🛠️ OOP Concepts Used

| OOP Concept       | Application in BUSPs Project                                                                                                                   |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **Encapsulation** | Classes encapsulate logic for login, candidate, voter management, and database connections.                                                    |
| **Abstraction**   | AbstractBUSPs class likely abstracts database setup and helper methods; UI actions abstract logic details.                                     |
| **Inheritance**   | Classes like LoginClass, ElectionLogic, CandidateLogic, VotingLogic, VoterLogic, DashboardLogic extend AbstractBUSPs for shared functionality. |

---

## 📦 Features

### User Login

* Secure login for admin and students.

### Election Management

* Admin can create, edit, and delete elections.

### Society Management

* Manage elections, candidates, and voters per society.

### Voting System

* One student = one vote per election.

### Result Calculation

* Auto-calculates and displays winning candidate.

---

## 💻 Technology Stack

* **Language & GUI:** Java Swing
* **Database:** MariaDB
* **Architecture:** Object-Oriented Programming (Encapsulation, Abstraction, Inheritance)
